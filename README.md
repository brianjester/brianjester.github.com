# Brian Jester's Portfolio

Portfolio of projects by Brian Jester in software development, amateur radio, education, investing, and travel. The public homepage is [brianjester.github.io](https://brianjester.github.io/).

## Featured projects

These projects are featured on the portfolio homepage:

- [ValueSlope](https://brianjester.github.io/value-slope/) - Compare annualized stock-price changes with return smoothness for S&P 500 stocks.
- [Travel Guide: Castles of Okinawa](https://a.co/d/4BS9E7q) - Explore 12 Okinawan castles, with nearby attractions and food recommendations.
- [Fun Filipino Words and Culture](https://a.co/d/4WbDkpE) - A bilingual children's book in Tagalog and English.
- [IndexFlip](http://indexflip.com) - Flashcards and practice tests for Japanese, amateur radio, driving, music, and real estate.
- [DMR QRZ](http://dmrqrz.com) - Look up Digital Mobile Radio contacts by radio ID or call sign.
- [Cabrillo Log](https://github.com/brianjester/brianjester.github.com/tree/master/cabrillo-log) - Create Amateur Radio contest logs in Cabrillo format.
- [SOTA Logs](https://github.com/brianjester/brianjester.github.com/tree/master/sota-log) - Create and manage CSV logs for Summits on the Air activations.
- [Passive Income](https://brianjester.github.io/passive-income/) - Track passive income from a collection of side projects.
- [Morse Code Key](https://brianjester.github.io/morse/) - Send Morse code in your browser using your mouse.
- [USGS Earthquake Map](https://github.com/brianjester/myExpressApp) - Explore USGS earthquake data in an Express and Mapbox map.
- [Castles of Okinawa Companion Site](https://brianjester.github.io/okinawa-castles/) - Browse companion information for the travel guide to 12 Okinawan castles.

The homepage also has a placeholder card: **More Projects Coming Soon** - Check back for new software, amateur radio, education, investing, and travel projects.
